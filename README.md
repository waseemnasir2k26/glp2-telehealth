# glp2-telehealth (VitalPath)

Front-end demo of a telehealth funnel for GLP-2 weight management, branded VitalPath. It is not a real clinic and not medical advice. All data is mocked and there is no real authentication.

Live: https://glp2-telehealth.vercel.app

## What is in it

- Public pages: landing, about, how it works, GLP-2 therapy, contact, and a 6-step patient assessment wizard.
- Legal pages: privacy, terms, telehealth consent, notice of privacy practices (template text, not legal advice).
- Mock patient portal: dashboard, appointments, messages, medications, records, settings.
- Mock admin area: dashboard and patient list.

The demo logins listed in the app are fake and protect nothing.

## Stack

Next.js 14 (App Router), TypeScript, Tailwind CSS 3.4, Framer Motion, Lucide React.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```
